1. Clone the repository:

   ```bash
   git clone https://github.com/sachinsainii/DSA_Python.git
   ```

2. Navigate into the folder:

   ```bash
   cd DSA_Python
   ```

3. Run any Python file:

   ```bash
   python filename.py
   ```
